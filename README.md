# API-тестирование в Postman

## О проекте

Учебный проект по тестированию REST API с использованием Postman.

В проекте реализованы автоматические проверки API, работа с переменными окружения, передача данных между запросами, динамические тестовые данные, проверка ответов и авторизация.

## Инструменты

- Postman
- REST API
- JavaScript
- Swagger

## Тестируемый сценарий

Запросы объединены в последовательный пользовательский сценарий:

1. `POST /users` — создание нового пользователя
2. `GET /users/{id}` — получение созданного пользователя по ID
3. `POST /auth/login` — авторизация созданного пользователя
4. `GET /profile` — проверка профиля авторизованного пользователя

Данные между запросами передаются автоматически с помощью переменных окружения Postman.

## Автоматизированные проверки

В коллекции реализованы проверки:

- HTTP-статусов;
- наличия обязательных полей;
- типов данных;
- значений в ответе;
- соответствия ID созданного пользователя;
- соответствия данных пользователя между запросами;
- роли пользователя;
- наличия токена авторизации;
- корректности авторизации.

Для регистрации используется динамический тестовый email.

## Найденный дефект

В ходе тестирования `GET /profile` был обнаружен дефект: после успешной регистрации и авторизации нового пользователя API возвращает данные профиля другого пользователя.

Дефект был оформлен отдельным баг-репортом.

## Структура проекта

- `QA Project.postman_collection.json` — коллекция Postman с запросами и автоматизированными тестами
- `QA Project.postman_environment.json` — окружение Postman
- `bugs/` — баг-репорт
- `screenshots/` — скриншоты результатов тестирования

## Окружение

API используется в локальном учебном окружении.

Адрес API:

`http://127.0.0.1:8000`

API не размещён в открытом доступе. Коллекцию Postman, автоматизированные проверки и структуру проекта можно изучить непосредственно в репозитории.

## Результат

Проект демонстрирует практические навыки API-тестирования в Postman:

- создание и отправка HTTP-запросов;
- работа с переменными;
- передача данных между запросами;
- написание автоматизированных проверок на JavaScript;
- тестирование авторизации;
- анализ ответов API;
- оформление баг-репортов.
